# YT Music Track & History Enhancer 🎵

Ekstensi Chrome / Edge / Brave untuk YouTube Music (`music.youtube.com`) yang melacak riwayat lagu sebenarnya, menghitung jumlah pemutaran (play counter), menyisipkan rak "Terakhir Diputar" di halaman depan, dan menambahkan tombol shortcut "Histori" langsung di sidebar navigasi.

---

## ✨ Fitur Utama

1. **Real-time Song Tracking & Scrobbler**:
   - Mencatat setiap lagu yang benar-benar Anda putar secara berurutan waktu (bukan algoritma rekomendasi YouTube Music).
   - Mengambil judul, artis, album, thumbnail resolusi tinggi, dan tautan lagu.
2. **Play Counter (Statistik Putar)**:
   - Menghitung berapa kali tiap lagu telah diputar (misal: `🔥 15x diputar`).
   - Cerdas: Hanya menghitung +1 putaran jika lagu didengarkan minimal 20 detik (dapat diatur di popup) untuk mencegah salah hitung saat skip cepat.
3. **Custom Shelf di Beranda (Homepage Enhancer)**:
   - Menyisipkan bagian khusus di halaman utama YouTube Music:
     - **🕒 Terakhir Diputar**: Daftar lagu yang baru saja Anda dengarkan secara kronologis.
     - **🔥 Paling Sering Diputar**: Lagu favorit yang paling banyak diputar.
   - Tombol **One-Click Play** pada setiap kartu lagu untuk langsung memutar ulang lagu tersebut.
4. **Shortcut Tombol "Histori" di Sidebar Navigasi**:
   - Menambahkan menu **"Histori"** langsung di sidebar kiri (sejajar dengan Beranda, Eksplorasi, Koleksi).
   - Membuka halaman riwayat resmi YouTube Music (`/history`) dengan satu klik tanpa perlu klik avatar profil.
5. **Dashboard Popup Ekstensi**:
   - Ringkasan total lagu unik dan total pemutaran.
   - Fitur pencarian lagu di riwayat.
   - Ekspor data riwayat ke file JSON (backup).
   - Pengaturan threshold detik pemutaran & toggle fitur.

---

## 🚀 Cara Memasang (Install) di Browser

1. Buka browser Chromium favorit Anda (Google Chrome, Microsoft Edge, Brave, Opera, dll).
2. Buka halaman ekstensi:
   - Chrome / Brave: ketik `chrome://extensions` di address bar.
   - Edge: ketik `edge://extensions` di address bar.
3. Aktifkan **"Developer mode"** (Mode Pengembang) di pojok kanan atas.
4. Klik tombol **"Load unpacked"** (Muat yang belum dibongkar).
5. Pilih folder ekstensi ini:
   ```
   F:\Extension\yt-music-tracker
   ```
6. Buka atau refresh tab [YouTube Music](https://music.youtube.com).
7. Selesai! Nikmati fitur pelacakan lagu otomatis, rak beranda baru, dan tombol histori langsung di sidebar.
